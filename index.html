☁ Cloud favorites

Your favorites folder, kept in a cloud bucket (Backblaze B2). Paste the manifest link once and the same favorites show up on any device, nothing to download or sign into.
How to set this up (one time)
  1. Create a free Backblaze B2 bucket (public), add the CORS rule, upload your favorites folder. The step-by-step is in SETUP.txt.
  2. Run make_manifest.py on your Arena save folder, upload the m-….json it creates along with the files.
  3. Paste the manifest's web address above and press Load. It is remembered, and re-read every time Arena opens, so new uploads appear on their own.
The manifest has an unguessable name: anyone who has the link can see the list, so keep it private. Cloud favorites aren't copied into your local folder.

☁ Google Drive

Use a Drive folder (and its sub-folders) as a pool source. It streams straight from Drive, so it works on a phone too.
How to set this up (one time) Everyone: get a key
  1. Go to console.cloud.google.com, create a project, then APIs & Services → Library → Google Drive API → Enable.
  2. Credentials → Create credentials → API key. Under restrictions pick API restrictions → Google Drive API and leave Application restrictions on None (videos can't send a referrer, so a website restriction would block them).
Simple mode (API key):
  1. In Drive, right-click the folder → Share → General access → Anyone with the link → Viewer. Copy the link.
  2. Paste the link and the key above, then Load. Anyone who has the folder link can open those files.
Private mode (sign in):
  1. OAuth consent screen: External, add your own Google account under Test users.
  2. Credentials → OAuth client ID → Web application. Add the address you open Arena from (e.g. https://yoursite.netlify.app) under Authorized JavaScript origins. This does not work from a local file.
  3. Paste the Client ID above, choose Private, press Sign in & load. Google warns the app is unverified: Advanced → continue (it is your own app).
On your phone: open Arena from a web address (for example drag the HTML file onto app.netlify.com/drop, or use GitHub Pages). Your keys are typed on the phone and never stored in the file.
